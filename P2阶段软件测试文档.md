# AgentService 平台 P2 阶段软件测试文档

> 版本: v2.0 ｜ 适用范围: P2 阶段新增功能（含 bd861bc 迭代） ｜ 编写日期: 2026-08-20

***

## 1. 测试概述

### 1.1 测试目标

验证 P2 阶段相对 P1 新增功能的正确性、稳定性与边界容错能力，确保各微服务（tool-svc / chat-svc / mem-svc / agent-svc）以及前端模块在以下维度功能可用：MCP 工具集成、Skill 渐进式披露与按需筛选、ReAct/Plan-and-Execute 对话编排、流式思考/回答分离、长期记忆自动评估、记忆深化。

### 1.2 P2 新增功能范围

| 模块             | 服务        | 核心能力                                                              |
| -------------- | --------- | ----------------------------------------------------------------- |
| MCP 服务管理       | tool-svc  | SSE/STDIO 双模接入、连接管理、工具发现、工具调用日志、web_search 兜底                    |
| Skill 管理       | tool-svc  | CRUD、3 级渐进式披露、本地/在线导入、Token 估算、按需关键词筛选                           |
| Agent 工具绑定     | agent-svc | Agent-MCP / Agent-Skill 绑定、tools-summary 汇总                       |
| ReAct 对话编排     | chat-svc  | 流式 SSE、Function Calling + 文本 ReAct 兜底、停止/重生成、思考/回答事件分离、P&E 工作模式 |
| 长期记忆自动评估       | chat-svc → mem-svc | 对话结束异步触发评估、LLM 适配器动态加载、结构化记忆更新                         |
| 记忆深化           | mem-svc   | Redis 短期缓存（内存回退）、长期记忆版本化、记忆摘要（含实际内容）                              |
| 前端交互增强         | frontend  | 用户消息复制/删除/回撤、Mermaid 图表渲染、Plan-and-Execute 计划卡片                  |

### 1.3 测试环境

- **后端**: Python 3.11 + FastAPI + SQLAlchemy(async) + MySQL 8.0 + Redis 7
- **前端**: Vue3 + Vite + Axios + Ant Design Vue
- **依赖服务**: MySQL（`infra/mysql/init.sql` 初始化）、Redis（可选）、LLM API（OpenAI/DeepSeek 兼容）
- **服务端口**: gateway=8000, agent-svc=8001, chat-svc=8002, tool-svc=8003, mem-svc=8004

## 2. 测试策略

### 2.1 测试分层

| 层级   | 范围                                | 工具建议                       |
| ---- | --------------------------------- | -------------------------- |
| 单元测试 | services/ 内业务方法、shared/domain 适配器 | pytest + pytest-asyncio    |
| 接口测试 | routers/ 下 REST API               | pytest + httpx.AsyncClient |
| 集成测试 | 跨服务调用（chat→tool→agent）            | pytest + httpx + 真实 DB     |
| 前端测试 | Vue 页面交互                          | Vitest + @vue/test-utils   |
| 手工验收 | 端到端 ReAct 流式对话                    | 浏览器 + curl SSE             |

### 2.2 通用前置条件

1. 已执行 `infra/mysql/init.sql`，20 张表创建完成
2. 已通过 P1 流程创建至少 1 个 LLM 配置和 1 个 Agent
3. Redis 可用（用于短期记忆缓存测试）；如不可用需验证内存回退
4. 准备一个可用的 MCP 服务（SSE URL 或 STDIO 命令）用于工具发现/调用测试

### 6.1 缺陷分级

| 级别    | 定义         | 示例                                                |
| ----- | ---------- | ------------------------------------------------- |

| P3 轻微 | UI/文案/性能优化 | 分页样式、提示文案、响应稍慢、关键词高亮样式                            |
